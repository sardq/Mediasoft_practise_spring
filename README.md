# REST API путеводителя по городу
Практика в Медиасофт зима-весна 2026 года. Разубаев Сергей ПИбд-41
# Описание проекта
Создан REST API для городского путеводителя. В сервисе можно смотреть список достопримечательностей, искать их в радиусе от себя (через координаты), фильтровать по категориям и рейтингу. Также добавлена возможность регистрации юзеров, выставления оценок (1-5) и написания отзывов. Для точного поиска по геолокации используется расширение PostGIS.
# Подготовительные действия
1. Java: Нужна версия 17.
2. БД: Установить PostgreSQL.
3. PostGIS: Обязательно нужно установить расширение PostGIS (через Stack Builder на Windows или apt install на Linux), иначе гео-запросы не заработают.
4. Создание БД: В PostgreSQL нужно вручную создать пустую базу с названием sights. Все таблицы и расширение PostGIS проект создаст сам через Liquibase при первом запуске.
# Информация о доступах
Настройки подключения в `src/main/resources/application.properties`:
- URL: `jdbc:postgresql://localhost:5432/sights`
- Логин: `postgres`
- Пароль: `postgres`
# Как запустить
1. Склонировать проект.
2. Открыть в IntelliJ IDEA.
3. Дождаться, пока Gradle скачает все зависимости.
4. Запустить класс MediasoftPractiseSpringbootApplication.
5. После запуска в консоли должно появиться сообщение, что тестовые данные загружены.
6. Swagger (документация API) будет доступен здесь: `http://localhost:8080/swagger-ui/index.html`
# Тесты
